# Pandas Basic Practice Questions

## Project Overview
This project contains solutions to basic Python Pandas practice questions completed as part of the Jobaaj Learnings placement preparation program.

## Objectives
- Create and inspect Pandas DataFrames.
- Select rows and columns.
- Filter data using conditions.
- Handle missing values.
- Calculate aggregates using `groupby()`.
- Sort and modify DataFrame values.
- Count categorical values.

## Technologies Used
- Python
- Pandas
- NumPy
- Kaggle Notebooks

## Project Files
- `pandas-basic-practice-questions.ipynb` — Notebook containing the assignment questions, Python solutions, and outputs.

## How to Run
1. Download the notebook or open it in Jupyter Notebook.
2. Install the required libraries:
   ```bash
   pip install pandas numpy
   ```
3. Run the notebook cells in order.

## Learning Outcome
Practised fundamental Pandas operations for data manipulation and analysis.
